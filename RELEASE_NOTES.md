# Outlast Trials Companion v1.0.0

Первый публичный релиз компаньона для The Outlast Trials.

## Что внутри

- **Справочник**: 14 локаций, 62 испытания, 24 предмета, 15 врагов, 4 рига.
- **Таймер**: точный таймер, чеклист задач, лучшее время и число забегов для каждого испытания.
- **Интерактивные карты**: схемы всех локаций с отметками пройденных зон и процентом исследования.
- **Офлайн-режим**: все данные и прогресс хранятся на устройстве.

## Файлы

- `OutlastTrialsCompanion-Setup-1.0.0.exe` — установщик для Windows (x64). Сам ставит приложение, создаёт ярлыки и деинсталлятор. Ничего дополнительно устанавливать не нужно.
- `OutlastTrialsCompanion-Portable-1.0.0.exe` — портативная версия для Windows (x64), запускается без установки.
- `OutlastTrialsCompanion-1.0.0.apk` — APK для Android 7+. Всё необходимое внутри.

## Установка

**Windows:** запустить Setup `.exe`, при предупреждении SmartScreen — «Подробнее» → «Выполнить в любом случае». Установщик не подписан сертификатом.

**Android:** открыть `.apk` на устройстве и разрешить установку из неизвестного источника.

**Браузер:** https://g1drohz.github.io/outlast-trials-companion/ — можно установить как PWA.

## Примечание

Fan-made проект, не аффилирован с Red Barrels. Схемы карт — упрощённые авторские планы, а не копии игровых карт. Данные могут отставать от патчей игры.
