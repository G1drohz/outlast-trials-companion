# Outlast Trials Companion v1.1.0

Большое обновление компаньона для The Outlast Trials: новый визуальный стиль, поддержка Linux и подробные схемы испытаний с легендой.

## Что нового

- **Новый дизайн:** кинематографичная тёмная палитра, мягкие панели, подсветки, обновлённые карточки, таймер, чеклист и легенда карт.
- **Linux:** сборки `AppImage` и `deb` для x86_64 добавляются в каждый релиз.
- **Подробные карты:** все 14 локаций перерисованы на 12 зон с реальными названиями площадок из открытых гайдов сообщества.
- **Легенда ключей:** добавлены отдельные типы зон «ключ» и «терминал» с маркерами прямо на схеме — сразу видно, где искать ключи, ключ-карты, предохранители и механизмы.
- **Точные данные:** обновлены описания Downtown, Shopping Mall и Resort — убраны неточные зоны из старых схем.
- **Офлайн-режим:** обновлена версия кэша Service Worker, чтобы PWA подхватило новые данные.

## Файлы

- `OutlastTrialsCompanion-Setup-1.1.0.exe` — установщик для Windows (x64).
- `OutlastTrialsCompanion-Portable-1.1.0.exe` — портативная версия для Windows (x64).
- `OutlastTrialsCompanion-1.1.0-x86_64.AppImage` — универсальный пакет для Linux (x86_64).
- `OutlastTrialsCompanion-1.1.0-amd64.deb` — пакет для Debian/Ubuntu (amd64).
- `OutlastTrialsCompanion-1.1.0.apk` — APK для Android 7+.
- Веб-версия: https://g1drohz.github.io/outlast-trials-companion/

## Установка

**Windows:** запустить Setup `.exe`. При предупреждении SmartScreen: «Подробнее» → «Выполнить в любом случае» — установщик не подписан платным сертификатом.

**Linux (AppImage):**
```bash
chmod +x OutlastTrialsCompanion-1.1.0-x86_64.AppImage
./OutlastTrialsCompanion-1.1.0-x86_64.AppImage
```

**Linux (deb):**
```bash
sudo apt install ./OutlastTrialsCompanion-1.1.0-amd64.deb
```

**Android:** открыть `.apk` и разрешить установку из неизвестного источника.

**Браузер:** открыть сайт и при желании установить как PWA.

## Примечание

Fan-made проект, не аффилирован с Red Barrels. Схемы — авторские планы для навигации, а не точные копии игровых карт. Спавны ключей и предметов в игре частично рандомизированы; данные основаны на открытых гайдах сообщества и могут отставать от патчей.
